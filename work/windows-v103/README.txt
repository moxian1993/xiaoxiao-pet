柯基小小v1.0.3 · Windows 脚本版
================================

系统要求
--------
Windows 10 或 Windows 11。
使用系统自带的 Windows PowerShell 5.1、WPF 和 Windows Script Host，
不需要安装 Python、Node.js、.NET SDK 或其他运行库。

启动
----
1. 先把整个 ZIP 解压到一个普通文件夹。
2. 双击“启动柯基小小.vbs”。
3. 桌宠不会显示任务栏按钮，退出请右键桌宠选择“退出柯基小小”。

请不要只在 ZIP 预览窗口里双击，也不要单独移动 VBS、PS1 或 assets 文件夹。

操作
----
- 启动后默认进入动态“陪伴”，每 2 秒随机眨眼、动耳朵或吐舌。
- 陪伴或注视时左键单击，会随机触发一个交互动作。
- 睡觉时左键单击，只会唤醒并回到陪伴。
- 按住左键可以拖动；程序会按当前动作帧的小狗实际透明轮廓判断触发区域。
- 从小狗自身轮廓顶部 35% 开始拖动会触发“拎起”，两耳之间的提起尖点会固定对齐鼠标；拎起和放下期间临时放大 1.5 倍，持续拖住时脚丫会循环划动；放下后立即恢复原大小和拖拽前的动作。
- 从小狗轮廓其他区域开始拖动只移动位置，不触发“拎起”。
- 右键不会改变当前状态，只打开菜单。
- “注视”是持续待机状态，会一直根据鼠标位置选择 16 个方向帧。
- “散步”随机执行内部的“跑步”或“跳跃”，持续 30 秒；跑步临时放大 1.3 倍，跳跃移动速度更快。
- “扭屁股”临时放大 1.3 倍，正向播放 2 遍后镜像再播放 2 遍。
- 选择静置动作时不会立即切换；当前状态不一致时重新计时，30 秒后应用。
- 静置动作选“睡觉”时，陪伴 30 秒后睡觉；选“陪伴”时会一直陪伴。
- 静置动作选“注视”时会持续注视；选“自动轮替”时，按“陪伴 → 注视 → 睡觉”循环。
- 自动轮替默认每 20 分钟切换一次，菜单内滑杆可设置 1～60 分钟并实时显示时间。
- 位置、大小、静置动作和置顶选项继续保存在 %APPDATA%\CorgiPetV24，可沿用旧版设置。

菜单
----
- 一级：陪伴、睡觉、注视、散步、扭屁股、待优化、大小、静置动作、始终置顶、退出。
- “待优化”：摸摸、连贯打滚、芭蕾旋转；跳跃作为散步的内部随机动作。
- 没有“重置位置”选项。

为什么没有 EXE
--------------
这个版本不分发自制 EXE。VBS 只负责隐藏启动 CorgiPet.ps1，真正窗口由
Windows 自带并由微软签名的 wscript.exe、powershell.exe 和 WPF 创建。
这种结构通常比一个全新的、没有信誉记录的 unsigned EXE 更不容易触发误报，
但任何脚本或程序都无法保证在所有杀毒软件上永不报警。

EXE 并非必须签名才能运行。受信任的代码签名可以显示发布者身份，并帮助后续
版本积累发布者信誉；但新的已签名文件仍可能先出现 SmartScreen 提示，EV 签名
现在也不会保证首次下载直接放行，更不能保证所有杀毒软件绝不误报。

无法启动时
----------
1. 确认 ZIP 已完整解压。
2. 双击“调试启动.bat”，把窗口里的错误截图发给开发者。
3. 如果单位电脑禁用了 VBS 或 PowerShell，需要由管理员允许；这属于系统策略，
   不是缺少运行库。
