# 柯基小小 v1.0.5 macOS 桌面宠物

这是一个完全独立的原生 macOS 应用，不依赖 Codex 或网络服务。

## 使用方式

- 首次双击 `柯基小小.app` 启动；从本版开始应用名称保持不变，版本号只在应用内部记录。
- 按住柯基身体左键拖动，可以移动位置。
- 陪伴或注视状态下左键单击柯基，会从交互动作池中随机触发一个；如果柯基正在睡觉，则本次点击只会唤醒并回到陪伴。
- 右键一级菜单直接提供陪伴、睡觉、注视、散步和扭屁股；摸摸、连贯打滚、芭蕾旋转放在“待优化”子菜单中。
- 右键菜单中的“大小”滑杆可以缩放桌宠，默认位置位于滑杆中间，缩放比例会自动保存。
- “静置动作”子菜单可以选择陪伴、睡觉、注视或自动轮替，选择会自动保存；如果当前状态不同，只记录选择并重新计时，30 秒后才应用。
- 自动轮替按“陪伴 → 注视 → 睡觉”循环，默认每 20 分钟切换一次；菜单内滑杆支持 1～60 分钟并实时显示当前时间。
- 右键菜单还可以切换始终置顶或退出应用。
- 右键选择“更新”可以安装本地发布目录中的新版，并自动备份、覆盖和重启。

## 本地更新

1. 修改代码或资源后，双击源码目录中的 `发布本地更新.command`。
2. 构建完成后，右键正在运行的柯基并选择“更新”。
3. 确认版本后，柯基会退出、安装新版并自动重新打开。

本地更新目录为 `~/Library/Application Support/柯基小小/Updates`，其中包含跨平台格式的 `update.json` 和 macOS ZIP。旧版会备份到同级的 `Backups` 目录，安装日志保存在 `Logs/local-update.log`。如果只发布了相同或更低构建号，应用会提示已经是最新版本。

远端更新可以继续复用相同清单、校验和安装流程，只需增加清单下载与安装包下载；正式对外发布前需要改用 Developer ID 签名和公证。

首次启动默认进入完整“陪伴”动作，而不是显示单张待机图。陪伴期间每隔 2 秒随机眨眼、动左耳、动右耳或播放吐舌小表情；“摸摸”保持为独立交互动作，不参与陪伴小动作池。交互动作结束后会回到当前选择的静置逻辑：陪伴继续陪伴，睡觉先回陪伴并在 30 秒后睡觉，注视继续注视，自动轮替则从陪伴重新开始轮替。前后待机状态相同时不会重复播放进入动作。

“注视”是持续待机状态，会一直读取鼠标相对桌宠的方向，并从现有 16 个方向帧中选择最接近的一帧，直到用户触发交互或切换状态。“散步”会随机选择内部的“跑步”或“跳跃”，持续移动 30 秒；跑步期间临时放大为 1.3 倍，结束后恢复用户原先设置的大小，跳跃的移动速度和范围更大。“扭屁股”期间临时放大为 1.3 倍，正向播放 2 遍后镜像再播放 2 遍。每次按下时会读取当前动作帧预先缓存的小狗透明轮廓，从轮廓自身顶部 35% 开始拖动才播放后颈受力的“拎起”；触发后会把两耳之间的提起尖点固定对齐鼠标，拎起和放下期间临时放大为 1.5 倍，持续拖住时循环脚丫划动，松开并放下后立即恢复原大小及拖拽前的动作。从轮廓其他区域开始拖动只移动位置，不触发拎起。睡觉动作当前暂时跳过第一组 8 帧，从第二组入睡帧开始播放。右键打开菜单本身不会改变当前状态。应用不会显示 Dock 图标，会记住上次拖动的位置、大小、静置动作和轮替时间，并显示在所有桌面空间。

V2 的三组新动作使用统一角色基准尺寸装配，播放过程中不做逐帧缩放；身体比例固定，动作只表现为关节姿势、位移和旋转变化。

“摸摸”会播放 6 帧由趴卧、开心抬头到重新趴下的完整动作；“注视”复用两行共 16 帧作为实时鼠标方向映射。

## 系统要求

- macOS 13 或更高版本。
- 同时支持 Apple 芯片和 Intel Mac。
